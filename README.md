# BioLab Insight · 生物制药实验智能分析智能体

面向生物制药实验室的 AI 智能体原型：自动对实验数据进行结构化总结，并针对不同实验结果定位可能的问题所在，给出按可能性排序的排查建议。

> 首届 OPC 创新应用挑战赛 · AiCoding 硬核组（场景应用赛道）· AI 智能体方向

## 快速开始

```bash
# 无需安装任何依赖（仅使用 Node.js 内置模块）
node server.js
# 打开 http://localhost:3000
```

云端部署时会自动注入 `PORT` 环境变量，服务监听 `0.0.0.0`，可直接发布。

打开页面后点击 **「载入演示数据」**，即可看到 23 条覆盖 17 类实验、含正常、异常与趋势漂移场景的记录及其诊断报告。

## 核心功能

| 功能 | 说明 |
|---|---|
| 实验记录录入 | 21 类实验、按 6 个类别分组：细胞培养/冻存复苏；蛋白纯化/Protein A 层析/超滤换液；SDS-PAGE/WB/qPCR/ELISA/SEC-HPLC/CE-SDS/HCP 残留；质粒制备/DNA 回收/转化；无菌检测/内毒素/微生物限度/环境监测；实验类别与实验类型为两级联动下拉（先选类别再选类型，选类型后类别自动同步）；每类实验的关键指标不同，并分为「关键指标 / 可选指标」两级（可选默认折叠）；指标支持多重复值自动计算 CV |
| 结构化实验总结 | 自动生成目的 / 方法 / 结果 / 结论四段式摘要 |
| 异常检测 | 指标越界、对照失效、重复孔 CV 过高、历史趋势漂移、多指标组合异常 |
| 问题定位 | 领域知识库 + 证据加权推理，输出疑似问题清单（可能性 / 严重程度 / 证据 / 原因 / 建议） |
| 健康度与预警 | 0–100 健康度评分，低 / 中 / 高 / 严重四级预警 |
| 历史对比 | 服务端保存全部记录，与同类历史批次做趋势对比 |
| 报告导出 | 打印 / 导出分析报告 |
| 实验操作知识库 | 21 个实验、155 个步骤，覆盖细胞/下游纯化/分析检测/分子/微生物；每步含操作要点、作用、可展开的详细子步骤、关键参数、观察判定与分级易错点；NanoDrop 读数提供 16 条解读规则；步骤中的试剂名称支持悬停查看知识卡 |
| 外观设置 | 字号四档（小/标准/大/特大）、五种背景颜色、夜间模式与跟随系统；偏好仅在内存中生效，不写入浏览器存储 |
| 实验问答 | **系统首页**，打开即进入问答；自然语言提问实验细节与疑惑（原理/作用、参数、判定、异常排查）；本地检索式问答，不联网、不调用外部大模型；每条回答标注来源（实验 + 第 N 步）可点击跳转，未命中时明确说明而非猜测 |

## 技术架构

- **后端**：Node.js 原生 `http` 模块构建 REST API，无第三方运行时依赖
- **前端**：原生 HTML / CSS / JavaScript 单页应用
- **数据存储**：服务端 JSON 文件（`data/experiments.json`）原子写入持久化。浏览器端不保存任何业务数据，不使用浏览器本地存储
- **分析引擎**：领域知识库（`lib/knowledge-base.js`）+ 推理引擎（`lib/analyzer.js`），规则可插拔，预留大模型接入适配点

```
Demo/
├── server.js              # HTTP 服务与 REST API
├── lib/
│   ├── knowledge-base.js  # 实验类型、指标阈值、诊断规则
│   ├── analyzer.js        # 推理引擎：异常检测、可能性评分、总结生成
│   ├── store.js           # 服务端持久化（原子写入）
│   └── qa-engine.js       # 实验问答：知识索引、中文检索、意图识别
│   ├── seed-data.js       # 演示数据
│   ├── protocol-knowledge.js # 实验操作知识库注册表与样板实验
│   ├── protocols/            # 20 个扩展实验模块（每个文件一个 SOP）
│   └── reagent-glossary.js   # 74 种试剂知识卡：作用、成分、注意事项、储存
├── public/                # 前端页面
├── data/                  # 运行时数据存储目录
└── package.json
```

## API 接口

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/types` | 获取实验类型与指标定义 |
| GET | `/api/experiments` | 实验记录列表与统计（可按 `?type=` 过滤） |
| POST | `/api/experiments` | 新建实验并分析（返回记录与报告） |
| GET | `/api/experiments/:id` | 单条记录详情 |
| DELETE | `/api/experiments/:id` | 删除记录 |
| POST | `/api/analyze` | 预览分析（不保存） |
| GET | `/api/stats` | 统计数据 |
| POST | `/api/seed` | 载入演示数据 |
| GET | `/api/health` | 健康检查 |
| GET | `/api/protocols` | 实验操作知识库条目列表 |
| GET | `/api/protocols/:id` | 单条实验 SOP（详细步骤、参数、观察判定、易错点、试剂知识卡） |
| GET | `/api/qa/suggestions` | 推荐问题与知识库覆盖范围 |
| POST | `/api/qa` | 实验问答（`{ question, context }` → 结构化答案 + 来源 + 追问） |

## 说明

本工具为研发与 QC 的**辅助决策支持**，不替代 GMP 放行判定、药典检验结论或专业人员的判断。领域阈值为通用工艺参考区间，实际使用应结合企业 SOP / 药典 / 注册工艺校准。
