# BioLab Insight · 生物制药实验智能分析智能体

面向生物制药实验室的 AI 智能体原型：自动对实验数据进行结构化总结，并针对不同实验结果定位可能的问题所在，给出按可能性排序的排查建议。

> 首届 OPC 创新应用挑战赛 · AiCoding 硬核组（场景应用赛道）· AI 智能体方向

## 快速开始

```bash
# 无需安装任何依赖（仅使用 Node.js 内置模块）
node server.js
# 打开 http://localhost:3000
```

云端部署时会自动注入 `PORT` 环境变量，服务监听 `0.0.0.0`，可直接发布。

打开页面后点击 **「载入演示数据」**，即可看到 6 条覆盖正常与典型异常的实验记录及其诊断报告。

## 核心功能

| 功能 | 说明 |
|---|---|
| 实验记录录入 | 细胞培养、蛋白纯化、qPCR、Western Blot、ELISA、无菌检测 6 类实验；指标支持多重复值自动计算 CV |
| 结构化实验总结 | 自动生成目的 / 方法 / 结果 / 结论四段式摘要 |
| 异常检测 | 指标越界、对照失效、重复孔 CV 过高、历史趋势漂移、多指标组合异常 |
| 问题定位 | 领域知识库 + 证据加权推理，输出疑似问题清单（可能性 / 严重程度 / 证据 / 原因 / 建议） |
| 健康度与预警 | 0–100 健康度评分，低 / 中 / 高 / 严重四级预警 |
| 历史对比 | 服务端保存全部记录，与同类历史批次做趋势对比 |
| 报告导出 | 打印 / 导出分析报告 |

## 技术架构

- **后端**：Node.js 原生 `http` 模块构建 REST API，无第三方运行时依赖
- **前端**：原生 HTML / CSS / JavaScript 单页应用
- **数据存储**：服务端 JSON 文件（`data/experiments.json`）原子写入持久化。浏览器端不保存任何业务数据，不使用浏览器本地存储
- **分析引擎**：领域知识库（`lib/knowledge-base.js`）+ 推理引擎（`lib/analyzer.js`），规则可插拔，预留大模型接入适配点

```
Demo/
├── server.js              # HTTP 服务与 REST API
├── lib/
│   ├── knowledge-base.js  # 实验类型、指标阈值、诊断规则
│   ├── analyzer.js        # 推理引擎：异常检测、可能性评分、总结生成
│   ├── store.js           # 服务端持久化（原子写入）
│   └── seed-data.js       # 演示数据
├── public/                # 前端页面
├── data/                  # 运行时数据存储目录
└── package.json
```

## API 接口

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/types` | 获取实验类型与指标定义 |
| GET | `/api/experiments` | 实验记录列表与统计（可按 `?type=` 过滤） |
| POST | `/api/experiments` | 新建实验并分析（返回记录与报告） |
| GET | `/api/experiments/:id` | 单条记录详情 |
| DELETE | `/api/experiments/:id` | 删除记录 |
| POST | `/api/analyze` | 预览分析（不保存） |
| GET | `/api/stats` | 统计数据 |
| POST | `/api/seed` | 载入演示数据 |
| GET | `/api/health` | 健康检查 |

## 说明

本工具为研发与 QC 的**辅助决策支持**，不替代 GMP 放行判定、药典检验结论或专业人员的判断。领域阈值为通用工艺参考区间，实际使用应结合企业 SOP / 药典 / 注册工艺校准。
